# 核心架构与设计规范

本文档是 NeuroBrain 当前的系统架构基线。核心模型的具体技术方案见 [核心模型技术方案 v0.1](core-model-technical-plan.md)。

## 项目定位

NeuroBrain 是一个独立、可训练、持续运行的人工心理动力系统。它通过学习外部刺激、内部状态与心理及行为变化之间的关系，形成具有特定性格倾向的动态心理反应机制。

核心目标是持续性、历史依赖性、可训练性、性格倾向、情绪与行为统一，以及脱离 LLM、AstrBot、Live2D 等应用独立运行。项目不以模拟生物神经元或实现生物大脑仿真为目标。

## 核心运行架构

```text
输入编码层 → 可训练心理动力核心 → 输出解码层
```

### 输入编码层

输入分为两个语义独立的通道：

1. **当前心理刺激**：当前事件对系统施加的新影响。
2. **历史情绪条件**：当前情境所带有的历史心理背景。

历史条件第一版使用固定预设数据，不依赖外部 Memory。它不能覆盖内部隐状态，也不能在每次更新时被重复当作新的刺激事件。

### 可训练心理动力核心

核心维护持续演化的内部隐状态，每次更新综合当前隐状态、输入、历史条件和时间间隔：

```text
下一时刻隐状态 = F(当前隐状态, 当前输入, 时间间隔)
```

第一版采用单层 CfC（Closed-form Continuous-time Neural Network）作为心理动力核心，内部隐状态暂定为 512 维。核心必须支持连续时间更新、无新刺激时继续演化、保留此前刺激影响、相同刺激在不同状态下产生不同响应，以及通过训练优化演化规律。

### 输出解码层

输入编码器暂定输出 32 维特征表示。心理状态和行为倾向都从同一个 CfC 隐状态读取，可以使用不同的输出解码器。行为倾向通过训练学习，不使用预先编写的大量固定情绪映射规则。

## 第一版输入输出协议

### 当前心理刺激

8 个维度：`joy`、`trust`、`fear`、`surprise`、`sadness`、`disgust`、`anger`、`anticipation`。每个值范围为 `[0, 1]`，表示当前新增刺激强度，不直接指定最终心理状态。

### 历史情绪条件

8 个维度，与心理状态维度相同。第一版采用固定条件；在具备训练数据后，再专项验证模型是否学会利用不同历史背景。

### 输出

- 心理状态：`joy`、`trust`、`fear`、`surprise`、`sadness`、`disgust`、`anger`、`anticipation`
- 行为倾向：`engagement`、`avoidance`、`expression`、`exploration`、`initiative`、`activation`

所有输出值暂定为 `[0, 1]`，允许多个维度同时存在。行为倾向表示内在倾向，不等于具体动作指令。

因此当前 v0.2 协议为 **16 维外部输入、14 维输出**。八维情绪是可解释的外部表示，不限制内部隐状态空间。

## 长期记忆边界

NeuroBrain 内部状态负责连续心理活动、短期状态残留和过去刺激的动态影响。具体历史经历由外部 Memory 系统管理，包括短期摘要、长期 Story 检索和存储。

未来 Memory 可以提供历史情绪标记、回忆刺激或历史条件，但第一版不接入真实 Memory。必须区分事件发生时的情绪、当前回忆产生的刺激，以及 NeuroBrain 当前计算出的心理状态。

## 外部集成边界

LLM 负责理解对话和情境、生成心理刺激，并结合 NeuroBrain 输出进行语言表达和行为决策。外部执行系统负责将决策转换为语音、Live2D 或 Agent 操作。NeuroBrain 提供独立、应用无关的输入输出接口。

## 研究原则

第一阶段先验证 CfC-512 的学习能力、历史依赖、泛化效果和运行性能，再根据实验结果调整模型容量或时间结构。所有模型变体必须使用相同的刺激序列和评价指标，比较连续性、历史依赖、稳定性、行为倾向一致性及训练前后差异。
