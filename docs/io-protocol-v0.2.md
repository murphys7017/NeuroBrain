# NeuroBrain 输入输出协议 v0.2

**协议状态：初始实验基线**  
**核心模型：CfC-512**

## 协议总览

```text
8 维当前情绪刺激 + 8 维历史情绪条件
→ CfC 心理动力核心
→ 8 维情绪状态 + 6 维行为倾向
```

情绪体系参考普鲁奇克的八种基本情绪，用于统一输入、输出和训练标注含义。它是可解释的外部表示，不对内部隐状态施加情绪轮结构或一一对应约束。

## 八维情绪空间

输入刺激、历史条件和情绪状态共享以下维度：

`joy`、`trust`、`fear`、`surprise`、`sadness`、`disgust`、`anger`、`anticipation`

每个值范围为 `[0.0, 1.0]`。多种情绪可以同时存在，输入表示外部影响，输出表示模型结合输入与内部状态后的当前状态。

历史条件与实时刺激保持独立：不能覆盖内部隐状态，不能被重复当作新的刺激事件。第一版允许使用固定预设值，之后再用不同历史条件的训练样本验证其作用。

## 输出定义

行为倾向输出为：

`engagement`、`avoidance`、`expression`、`exploration`、`initiative`、`activation`

情绪输出不使用 Softmax，不要求总和为 1，也不把普鲁奇克情绪轮中的对立关系变成硬约束。情绪之间的促进、抑制、转换、持续和恢复由训练学习。

行为倾向表示行为动机或活动倾向，不等于具体动作指令。情绪与行为共享同一个 CfC 隐状态，通过独立解码器输出。

## 模型配置

| 模块 | 配置 |
|---|---|
| 当前刺激 | 8 维 |
| 历史情绪条件 | 8 维，预设 |
| 输入编码层 | 32 维 |
| 核心算法 | CfC |
| 内部隐状态 | 512 维 |
| 情绪解码器 | 8 维 |
| 行为解码器 | 6 维 |

## 训练数据

每条训练序列包含场景初始条件、按时间排列的八维刺激、关键时间点的八维目标情绪状态、六维目标行为倾向，以及事件时间和状态变化时间信息。

训练目标覆盖刺激相互作用、响应强度、持续与恢复、内部状态影响、多情绪共存、情绪与行为关系，以及符合目标性格的反应规律。LLM 可以辅助生成标注，但必须经过一致性和合理性检查。

## 扩展原则

后续可以增加心理状态、行为倾向或外部刺激维度，但必须保持输入编码器、CfC 核心和输出解码器之间的模块边界。八维情绪协议是实验基线，不是内部状态空间的容量限制。
