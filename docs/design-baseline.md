# NeuroBrain — 核心架构与设计规范

> **历史文档：** 本文档记录 v0.1 的 5 维情绪协议，已由 [输入输出协议 v0.2](io-protocol-v0.2.md) 取代。当前实现和实验应以 v0.2 及 CfC 核心模型方案为准。

**项目阶段：初期设计**

**文档性质：项目设计基线**

## 一、项目定位

NeuroBrain 是一个独立、可训练、持续运行的人工心理动力系统。

系统通过学习外部刺激、内部状态与心理及行为变化之间的关系，形成具有特定性格倾向的动态心理反应机制。

项目的核心目标包括：

1. **持续性**：人工大脑拥有持续演化的内部状态，不依赖外部对话触发运行。
2. **历史依赖性**：过去受到的刺激会通过内部状态影响后续心理与行为反应。
3. **可训练性**：心理变化规律由模型从训练数据中学习，并能够通过新增案例持续优化。
4. **性格倾向**：通过具有特定性格特征的训练数据，使模型学习相对稳定的心理反应规律。
5. **情绪与行为统一**：心理状态与行为倾向由同一个人工心理动力核心共同产生。
6. **独立性**：人工大脑能够脱离 LLM、AstrBot、Live2D 等外部应用独立运行。

系统不以模拟生物神经元、生物神经网络或实现生物大脑仿真为目标。

内部算法与网络结构服务于人工心理系统的学习能力、动态表现和长期扩展需求。

## 二、核心运行架构

整体结构为：

**输入编码层 → 可训练心理动力核心 → 输出解码层**

### 1. 输入编码层

负责接收和处理外部输入，并转换为核心模型可以使用的数据。

输入分为两类：

- 当前心理刺激
- 历史情绪条件

不同输入具有独立语义，不直接混合为同一种刺激。

输入编码层应保留可扩展性，以便未来增加其他信息来源。

### 2. 心理动力核心

这是 NeuroBrain 的主要组成部分。

核心模型拥有持续演化的内部隐状态。

每次状态更新时，模型综合：

- 当前内部状态
- 外部刺激
- 历史条件
- 经过的时间
- 已训练形成的状态演化规律

计算新的内部状态。

其基本形式为：

`下一时刻隐状态 = F(当前隐状态, 当前输入, 时间间隔)`

其中，F 代表可训练的心理状态演化模型，历史条件可作为当前输入中的独立条件信息参与计算。

核心应满足：

1. 内部状态能够在连续时间过程中更新。
2. 没有新刺激时仍能进行状态演化。
3. 能够保留并利用此前刺激的影响。
4. 相同刺激能够因内部状态不同而产生不同响应。
5. 内部状态演化规律能够通过训练优化。
6. 支持后续扩展输入、输出及模型表达能力。

**具体神经网络算法不在本阶段固定，以可训练性、状态表达能力、运行稳定性和扩展性作为选型依据。**

### 3. 输出解码层

输出解码层从共享的内部隐状态中读取：

- 当前心理状态
- 当前行为倾向

两个输出组共享同一个心理动力核心。

行为倾向不通过预先编写的固定情绪映射规则生成，而应通过训练学习与内部状态的关系。

## 三、第一版输入规范

### 1. 当前心理刺激

暂定使用 5 个情绪刺激维度。

| 参数 | 含义 |
|---|---|
| Joy | 高兴、愉悦刺激 |
| Sadness | 悲伤、失落刺激 |
| Tension | 紧张、不安刺激 |
| Curiosity | 好奇、探索刺激 |
| Surprise | 惊讶、意外刺激 |

刺激强度暂定使用 0～1 的数值范围。

0 表示没有新增刺激，1 表示较强刺激。

输入表示外界施加的心理影响，不直接指定人工大脑应当达到的最终状态。

### 2. 历史情绪条件

保留独立的历史情绪输入。

第一版采用固定的预设历史情绪数据，不依赖外部记忆系统。

历史情绪条件暂定沿用 5 个维度：

- Joy
- Sadness
- Tension
- Curiosity
- Surprise

该输入用于提供历史心理背景，与当前刺激具有不同含义。

要求：

1. 历史条件不能直接覆盖当前神经隐状态。
2. 历史条件不能在每次更新时被重复视为新的刺激事件。
3. 第一版保留输入通道，使用预设数据。
4. 历史条件对动态反应的实际影响，在后续具备训练数据后进行专项学习与验证。

若初期历史条件始终固定，不能据此认定模型已经学会处理不同历史背景。

### 3. 内部状态

内部状态由心理动力核心自行维护。

短期情绪变化、心理趋势、状态残留及此前刺激影响均通过内部状态及其递归演化机制体现。

不建立额外的独立短期心境计算系统。

## 四、第一版输出规范

### 1. 心理状态输出

暂定 5 个维度。

| 参数 | 含义 |
|---|---|
| Joy | 当前高兴程度 |
| Sadness | 当前悲伤程度 |
| Tension | 当前紧张程度 |
| Curiosity | 当前好奇程度 |
| Surprise | 当前惊讶程度 |

输出数值暂定归一化至 0～1。

允许多种情绪同时存在。

心理输出必须反映模型结合内部状态和输入后计算出的结果，而不是简单复制刺激强度。

### 2. 行为倾向输出

暂定 6 个维度。

| 参数 | 含义 |
|---|---|
| Engagement | 与外界互动、建立联系的倾向 |
| Avoidance | 回避、退缩或减少刺激的倾向 |
| Expression | 表达情绪及想法的倾向 |
| Exploration | 观察、探索及了解未知事物的倾向 |
| Initiative | 主动发起行为的倾向 |
| Activation | 当前整体行为活跃程度 |

行为倾向表示当前可能采取某类行为的内在倾向，不等同于具体动作指令。

不同倾向可以同时存在，甚至表现出一定冲突。

行为输出与心理输出共享内部隐状态，通过训练形成相互关联的响应规律。

具体动作的选择、组织与执行由外部应用完成。

### 3. 输入输出规模

第一版暂定：

| 类型 | 维度 |
|---|---:|
| 当前心理刺激 | 5 |
| 历史情绪条件 | 5 |
| 心理状态输出 | 5 |
| 行为倾向输出 | 6 |

**合计：10 维外部输入、11 维输出。**

其中历史输入第一版采用固定条件，尚不要求模型具备完整的历史情绪理解能力。

以上参数属于初始实验协议，可在后续训练研究中调整。

## 五、训练与学习机制

### 1. 训练目标

训练心理动力核心，使其能够从连续刺激及内部状态中学习合理的心理与行为变化规律。

训练内容不仅包括最终情绪数值，还包括变化过程、持续时间、历史依赖及行为倾向。

角色的性格通过训练数据所体现的心理反应模式进行塑造。

### 2. 训练数据来源

初期使用具有情绪变化的剧本、故事片段和互动场景。

通过 LLM 辅助生成结构化训练数据，包括：

- 按时间排列的事件及心理刺激
- 场景初始状态
- 关键时间点的期望心理状态
- 关键时间点的期望行为倾向
- 刺激与状态变化之间的时间关系

训练案例应具有连续的时间结构，能够体现多个刺激之间的相互影响。

LLM 标注属于合成监督数据，需要进行合理性及一致性检查。

### 3. 模型训练

基本流程为：

**训练案例 → 输入及目标序列 → 模型运行 → 计算误差 → 优化模型参数**

训练目标包括核心内部状态演化规律及其输出映射。

训练过程中需要保证模型能够稳定运行，并具备利用历史状态的能力。

### 4. 持续优化

初始模型训练完成后，允许持续补充参考案例。

优化流程为：

**新增案例 → 数据审核 → 训练更新 → 对照评价 → 发布新版本**

要求：

1. 保留原始训练案例。
2. 新旧数据能够共同参与训练。
3. 能够比较不同模型版本的表现。
4. 能够保存和恢复模型版本。
5. 正式运行与训练更新相互隔离。

第一版不要求实时在线更新模型权重。

## 六、长期记忆与历史经历

NeuroBrain 的内部状态负责连续心理活动及过去刺激产生的影响。

具体历史经历由外部 Memory 系统管理。

现有 Memory 提供：

- **短期记忆**：近期对话内容的摘要。
- **长期记忆**：通过向量相似度检索取得相关 Story。

NeuroBrain 不重复实现对话摘要、向量检索或 Story 存储。

后续可以让 Story 携带对应的历史情绪标记，并结合当前情境形成历史条件或回忆刺激。

需要明确区分：

1. 历史事件发生时的情绪。
2. 当前回忆事件时受到的心理刺激。
3. NeuroBrain 当前实际产生的心理状态。

第一版只保留固定历史情绪输入，不要求接入真实 Memory 数据。

历史数据积累后，再开展相关条件输入的专项训练。

## 七、评价与观察

评价系统用于验证模型是否真正学到了合理的心理及行为动态规律。

包含两个主要方向。

### 1. 互动观察

通过具有指定人格的 LLM 角色与用户进行对话。

LLM 将当前对话转化为刺激，NeuroBrain 产生心理及行为状态，再将输出提供给角色生成过程。

观察内容包括：

- 当前输入刺激
- 人工大脑的心理输出
- 行为倾向输出
- 状态随时间变化的过程
- 角色实际对话与行为表现

LLM 对心理状态的自然语言描述属于解释信息，需要与人工大脑的真实数值输出区分。

### 2. 标准化评价

使用固定的刺激序列和参考目标进行可重复测试。

评价重点包括：

- 心理变化的合理性
- 时间连续性
- 历史依赖性
- 行为倾向的一致性
- 长时间运行稳定性
- 模型训练前后的效果差异
- 新增训练数据后的旧能力保持情况

评价系统用于支持技术选择和后续模型优化。

## 八、外部集成

NeuroBrain 作为独立系统运行。

对外提供统一的输入和输出能力，不依赖具体的 LLM、Agent 框架或视觉表现系统。

在 AG99 中的职责分工为：

**LLM**

负责理解对话与情境、生成心理刺激，以及结合人工大脑状态进行语言表达和具体行为决策。

**NeuroBrain**

负责持续维护内部心理状态，学习刺激与心理变化规律，并输出心理状态和行为倾向。

**外部执行系统**

负责将行为决策转换为具体操作、语音表现或 Live2D 动作。

NeuroBrain 输出可以反馈给 LLM，影响后续对话及行为决策。

## 九、第一阶段开发范围

第一阶段仅构建一个人工大脑。

### 必须实现

1. 独立运行的可训练心理动力核心。
2. 持续演化的内部隐状态。
3. 当前心理刺激输入。
4. 固定历史情绪条件输入。
5. 共享隐状态的心理与行为倾向输出。
6. 模型训练及参数保存。
7. 基础状态观察与效果验证。
8. 可供外部系统调用的标准接口。

### 后续扩展

- 历史情绪条件专项训练。
- Memory / Story 接入。
- 历史经历相关心理刺激生成。
- 电脑运行状态与环境感知。
- 更复杂的行为意图输出。
- 正式互动实验室。
- AG99、AstrBot 和 AG99live 的完整集成。
- 在线学习及更复杂的持续优化机制。

### 不属于当前范围

- 多大脑、多角色及多人格管理。
- 多用户状态隔离。
- 分布式心理动力系统。
- 完整生物神经系统仿真。
- 直接替代 LLM 的语言理解和生成能力。

## 十、核心设计原则

NeuroBrain 是一个以训练为基础的人工心理动力系统。

核心设计遵循以下原则：

1. **心理规律通过训练学习**，避免依赖大量人工编写的固定映射规则。
2. **内部状态负责短期历史**，不在外部重复维护短期心境。
3. **长期具体经历由 Memory 承担**，人工大脑只接收相关的条件或刺激。
4. **情绪和行为共享一个核心**，共同反映内部状态的演化。
5. **模型结构保持可扩展性**，具体技术方案以实际学习效果为依据。
6. **训练与运行相互独立**，支持新版本验证及回滚。
7. **人工大脑保持应用无关**，可独立训练、运行和提供状态输出。

## 十一、项目目标

NeuroBrain 第一阶段的核心成果，是一个能够独立运行、接受外部刺激、持续演化内部状态，并通过训练生成合理心理及行为倾向的人工系统。

在此基础上，通过持续增加参考案例、优化动态模型、扩展输入来源与接入现有记忆系统，使其逐步形成更加稳定、丰富且符合目标性格的心理反应规律。

**最终目标：构建一个可训练、可持续演化、可扩展，并能够为 AI 角色提供连续心理状态与行为动机的人工心理系统。**
