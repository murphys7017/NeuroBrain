# NeuroBrain 核心模型技术方案 v0.1

**文档类型：核心模型设计规范**  
**当前阶段：模型构建与初始实验**

## 一、技术选型

第一版采用 **CfC（Closed-form Continuous-time Neural Network，闭式连续时间神经网络）** 作为人工心理动力系统的核心模型，开发框架采用 PyTorch，优先参考 `ncps.torch.CfC` 实现。

核心模型负责接收心理刺激与条件信息、维护和演化内部隐状态、保留此前刺激影响，并学习心理状态与行为倾向的动态变化规律。模型不以模拟生物神经元或生物神经系统为设计前提。

## 二、模型架构

```text
输入编码器（32 维） → 单层 CfC 心理动力核心（512 维隐状态） → 多输出解码器（8+6 维）
```

### 输入编码器

输入包含当前心理刺激 8 维和历史情绪条件 8 维，采用 Joy、Trust、Fear、Surprise、Sadness、Disgust、Anger、Anticipation。历史条件初期使用预设数据，不等同于当前心理状态，也不代表新发生的刺激。编码器暂定输出 32 维特征表示，具体融合方式在实现阶段通过实验确定。

### CfC 心理动力核心

采用单层 CfC 递归核心，内部隐状态维度为 512。模型学习当前输入、已有隐状态和时间间隔之间的动态关系：

```text
h(t + Δt) = CfC(h(t), x(t), Δt)
```

512 维表示内部状态空间规模，不对应情绪种类或生物神经元数量。核心要求支持递归状态传递、非线性刺激响应、梯度训练和后续容量扩展。

### 输出解码器

输出解码器共享 CfC 隐状态，分为：

- 心理状态：8 维 `joy`、`trust`、`fear`、`surprise`、`sadness`、`disgust`、`anger`、`anticipation`
- 行为倾向：6 维 `engagement`、`avoidance`、`expression`、`exploration`、`initiative`、`activation`

两组输出暂定归一化到 `[0, 1]`。行为倾向通过训练学习，不使用固定的情绪到行为映射，也不等于具体动作指令。

## 三、训练方案

第一版采用基于时间序列的监督学习。训练案例包含连续事件、心理刺激、场景初始状态、关键时间点的心理状态、行为倾向和时间关系。

```text
参考案例 → 结构化时间序列 → CfC 预测 → 误差计算 → 参数优化
```

输入编码器、CfC 核心和输出解码器均参与训练。重点验证刺激交互、内部状态影响、心理与行为联系，以及刺激消失后的恢复轨迹。历史情绪条件第一版使用预设数据，不要求完成不同历史背景的专项学习。

训练和正式运行相互独立，后续支持新增样本、模型版本比较、参数保存和恢复；第一版不要求在线更新权重。

## 四、初始实验

1. **模型结构验证**：确认输入、隐状态维护和输出链路正确。
2. **基础心理动态**：验证简单刺激下的变化与恢复轨迹。
3. **连续刺激与历史依赖**：比较不同刺激顺序和内部初始状态的响应。
4. **行为倾向学习**：验证共享隐状态同时支持情绪和行为输出。
5. **模型容量与性能**：测量 CfC-512 的参数规模、训练成本、推理性能和稳定性。
6. **泛化能力**：使用未参与训练的参考场景验证推广能力。

## 五、第一版技术配置

| 项目 | 配置 |
|---|---|
| 核心算法 | CfC |
| 开发框架 | PyTorch |
| 参考实现 | `ncps.torch.CfC` |
| 隐状态规模 | 512 维 |
| 递归核心层数 | 1 |
| 输入编码维度 | 32 |
| 当前刺激输入 | 8 维 |
| 历史情绪条件 | 8 维，预设 |
| 心理状态输出 | 8 维 |
| 行为倾向输出 | 6 维 |
| 模型训练 | 基于时间序列的监督学习 |
| 部署范围 | 单个独立人工大脑 |

## 六、扩展原则

后续允许扩展隐状态规模、输出维度、输入编码、多时间尺度动态、历史条件专项训练、Memory 接入和持续训练。模型扩容或结构调整后允许重新训练或迁移参数，不要求新旧权重天然兼容。扩展取舍以可训练性、稳定性和实际心理表现为依据。

## 七、当前运行方式

当前模型已经提供两层调用接口：

- `NeuroBrainSession`：面向业务集成，每次接收一个 8 维当前刺激，在 session 内保存隐状态，适合角色、Agent 和服务端宿主程序。
- `NeuroBrainModel`：面向训练和实验，可以显式传入 8 维历史条件、每步 `delta_seconds` 和 `hidden_state`，适合批量序列和底层研究。

公开 facade 将历史条件固定为全零，因此公开调用要求 checkpoint 使用 `history_mode=zeros`。
仓库提供可选的 JSON WebSocket 状态服务，但不内置 HTTP；需要其他网络接口时仍由宿主应用包装
Python facade。启动、checkpoint 和外部调用示例见 [上手与运行](getting-started.md)、
[Python 推理接口](python-api.md) 和 [外部集成](integration.md)。
