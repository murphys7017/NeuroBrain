# 项目定位与术语

当前实现的安装、启动和调用入口见 [上手与运行](getting-started.md)。对外集成优先使用 [Python 推理接口](python-api.md)；网络服务需要由宿主应用自行包装，具体边界见 [外部集成](integration.md)。

## 目标

NeuroBrain 研究一种具有时间连续性、历史依赖性和可学习性的人工动力系统。它不以完整模拟生物大脑或证明主观意识为目标，而是为角色和 Agent 提供可持续演化的内部状态。

核心闭环为：

```text
当前刺激与历史条件 → 输入编码 → 心理动力核心 → 持续状态演化 → 心理状态与行为倾向 → 外部决策与执行
```

## 核心术语

- **刺激（stimulus）**：外界事件对系统施加的结构化影响，不等于角色最终状态。
- **历史情绪条件（historical emotion condition）**：当前情境携带的历史心理背景，和当前刺激保持独立语义。
- **心理状态（psychological state）**：神经网络演化后的连续输出，可同时包含多个维度。
- **行为倾向（behavior tendency）**：当前更愿意做什么的倾向，不等于已经执行的动作。
- **内部状态（internal state）**：保留历史影响、决定后续响应的网络状态。
- **行为执行器（executor）**：将外部决策转换成 Live2D、语音、对话或 Agent 操作的系统。
- **外部 Memory**：负责短期摘要、长期 Story 检索和具体历史经历存储，不由 NeuroBrain 重复实现。

## 当前非目标

第一阶段不处理多角色管理、分布式部署、完整生物大脑仿真、自主意识系统，也不让人工神经网络直接替代 LLM。
