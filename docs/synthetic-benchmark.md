# 合成状态动力学基准

运行 `uv run --locked python scripts/synthetic_benchmark.py` 可生成随机序列、训练一个新的 CfC-512，并评估从未参与训练或选轮次的测试序列。实验数据和 checkpoint 都只放在内存里，不会覆盖项目语料或模型文件。可用 `--device cpu`、`--epochs` 和 `--train-seed` 等参数调整运行。

老师系统从零状态开始，逐维执行连续时间低通更新：

```text
alpha = 1 - exp(-0.55 * delta_seconds)
emotion_t = emotion_(t-1) + alpha * (stimulus_t - emotion_(t-1))
```

每条 16 步序列的刺激从均匀随机数生成，并独立将约 30% 的维度置零；时间间隔在 0.3 至 2.0 秒之间随机。6 维行为目标由情绪状态通过固定、可解释的线性组合生成。训练输入只有当前刺激、全零历史条件和时间间隔；老师状态只用于产生目标，不会反馈为模型输入。

默认使用独立随机种子生成 128 条训练序列、32 条验证序列和 64 条测试序列，模型按验证集误差选择轮次。报告情绪与行为头各自的 MAE/MSE，并与训练目标均值基线比较。MSE skill 定义为 `1 - model_mse / train_mean_baseline_mse`。方向命中率只统计老师相邻状态变化大于 `0.03` 的维度。最后还会检查 joy/fear 脉冲与无刺激恢复轨迹，以及不同前史之后输入相同中性刺激时的状态差异。

## 2026-10-10 基线结果

使用默认配置，在 RTX 4070 上训练 60 轮，最佳验证轮次为第 59 轮，训练耗时约 19 秒。独立测试结果如下：

| 输出头 | 模型 MAE | 均值基线 MAE | 模型 MSE | 均值基线 MSE | MSE skill |
|---|---:|---:|---:|---:|---:|
| 情绪 | 0.03066 | 0.16327 | 0.00148 | 0.03848 | 0.962 |
| 行为 | 0.01199 | 0.08319 | 0.00025 | 0.01098 | 0.978 |

老师状态变化超过 `0.03` 时，情绪方向命中率为 `98.9%`，行为方向命中率为 `99.8%`。在四步满强度 joy/fear 脉冲之后，模型能跟随上升并在撤除刺激后回落，但尾部恢复偏慢：第 8 个无刺激步的老师状态约为 `0.011`，模型约为 `0.067`（joy）和 `0.052`（fear）。经过 joy 与 fear 两种不同前史后再输入相同中性刺激，老师状态的最大差异为 `0.513`，模型为 `0.423`，说明模型保留了前史影响，但幅度仍有低估。

这不是心理学效度测试。合成目标由已知公式生成，随机测试只验证对同分布合成序列的学习与泛化；它不能证明真实角色状态、真实标注质量、未见场景泛化或真实刺激语义正确。GPU 运行使用固定数据与初始化种子，但不同硬件或内核可能产生轻微数值差异。
